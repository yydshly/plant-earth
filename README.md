# 植物地球 · Plant Earth

面向成年人的植物地理有声图谱。通过地球、展开地图、植物形态、地区环境证据和同步讲解，理解植物为什么分布在不同地方。

**在线网站：https://yydshly.github.io/plant-earth/**

**项目总览、使用路线、资料覆盖与后续计划：https://yydshly.github.io/plant-earth/about.html**

- 144个代表条目：100个农业与园艺条目，44个其他代表植物；条目不是独立物种数量。
- 89个地区案例；气候、根区与水源资料注明时期、单位、来源和适用边界。
- 445段现用MiniMax录音；字幕和地球展示使用同一录音时钟。
- 国家农业统计、原生与引入记录、代表地区与气候候选分别表达。
- 按问题进入、课程目录、连续播放、植物对照和个人解释回顾。

进入后选择一个问题，或通过课程目录直接进入植物、地区与地理基础。点击播放才开始讲解；可以暂停、回看、展开地图，再回到当前讲解位置。

网站保留七个学习模块：地球与地理基础、生态环境、农业与园艺分类、其他代表植物、全球地区课堂、真实分布地图、综合回顾。首页、各课堂页和课程目录都有项目说明入口；总览页提供模块直达链接和资料边界，阅读总览无需载入地球或录音。

基础与生态课程共用课程工具栏，视图切换、标题和换课控件在栏内排布；当前场景提示并入持续存在的播放器，详细图解和说明按需展开。布局切换保留同一录音与时钟；退出模块时清除提示卡。观看布局由`unified-globe.css`统一管理，避免分别预留浮动工具栏与提示卡的空间。

后续按四步推进：先组织成人首次使用测试，验证定位、解释和证据辨别；再补关键土壤缺项与跨地区对照；逐批补充实物识别图；根据试用结果和地区、类群覆盖缺口扩展课程。每一步的当前状态、行动与拟定验收条件在总览页公开。真人试用尚未验收，计划标准不表示已达成。

学习反馈和资料纠错分别使用GitHub议题模板，链接位于总览页。网页不会自动上传本地学习记录；反馈由访问者自行选择提交。

新增四课以红草、望天树、北极柳和樟树对照草原、雨林林冠、苔原和城市绿地。四处均有NASA月度气候、JRC水面像元与文献机制资料；新点未取得SoilGrids数值，界面保留缺项并单独展示有来源的根区说明。樟树的原生身份保留WCVP与香港资料之间的分歧。新增四张实物照片都有作者、许可与来源。

同一录音用于不同入口时，原文、字幕时间与时长必须完全一致。437段原有录音保留，其中两段含旧条目数量的导览已更新为新版本；旧音频继续兼容已打开的旧页面。新增资料与生成记录见`sources/expansion-wave3.json`，安装器为`scripts/install-wave3.py`。

## 本地开发

需要Node.js 22.15及以上版本和Python 3。运行`npm ci`，然后`npm run build`、`npm run check`。在项目目录运行`python -m http.server 8000`，访问`http://127.0.0.1:8000/`。

修改`src/`中的界面代码和根目录CSS后重新构建。`data.js`是经过校验的固定资料与录音清单；修改讲稿需要生成新的录音版本和字幕，不能直接改文字后沿用旧录音。

`about.html`由`scripts/build-project-overview.mjs`生成，不单独手改。覆盖数量使用`src/project-overview-model.js`从正式资料计算，与首屏延后载入状态无关；计划状态维护在`src/project-overview-content.js`。首页和课程目录与总览共享已有导航，继续使用原播放器与学习记录。`scripts/check-overview.mjs`检查覆盖数量、七个模块链接、页内锚点和GitHub项目子路径；发布检查同时核对两个HTML页面的资源与版本哈希。

## 发布

推送`main`触发GitHub Actions：从源码构建、检查固定资料与资源、只将`site-files.json`列出的文件发布到GitHub Pages。所有页面资源使用相对路径，支持项目子路径。媒体为独立文件，按播放器或图片需要加载；首页不包含全库录音的Base64数据。

仓库中不含API密钥、付费接口回执、个人学习记录、原始抓取缓存、离线单文件或本机开发依赖。网站播放现有录音，不调用MiniMax付费接口。个人学习状态保存在访问者自己的浏览器中。

首次打开所需的样式、程序和压缩课程资料随首页一次送达，减少串行请求。地球地理、全部植物与地区课程、录音清单、字幕时间和教学坐标完整还原后，才初始化播放器与地球；较大的全球统计记录与植物区系边界在首帧后加载。全球明细未齐时明确显示载入状态，失败可重试，不能把未载入画成零值或“没有记录”。明细到达只更新地图资料，不重建播放器、不暂停或跳转讲解。

压缩仅改变传输格式；首屏使用有SHA-256校验的Zstandard帧和本地捆绑的fzstd解码器，全球明细使用gzip。构建时通过同一个浏览器解码器逐字段比较完整还原结果，并检查首屏资料中453个讲解入口的1359个步骤时间与字幕。录音、字幕、坐标和时钟不作删改。不支持所需浏览器功能或压缩资料校验失败时回退到同一版完整`data.js`和`app.js`。初始化完成前有加载提示，失败可手动重试，加载器不会覆盖课程自己的焦点管理。

## 资料与表达边界

来源、许可及支持范围保存在`sources/`，也可在网站资料栏查看。植物实物照片的作者、许可和原始页面在`sources/plant-photos.json`及`sources/expansion-wave3.json`；NASA地表图的来源与处理过程在`sources/earth-surface-provenance.json`。第三方代码许可证见`THIRD_PARTY_NOTICES.txt`。

国家生产统计、粗区系记录和地区采样点不能证明具体田块适生；教学模型、山形、风与水循环符号不是现场重建或实时观测。句内定位使用文字位置估算，不是逐词强制对齐。网站适合科普与比较学习，数据覆盖和缺失在界面明确说明。
