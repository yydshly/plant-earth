# 植物地球 · Plant Earth

面向成年人的植物地理有声图谱。通过地球、展开地图、植物形态、地区环境证据和同步讲解，理解植物为什么分布在不同地方。

**在线网站：https://yydshly.github.io/plant-earth/**

- 140个代表条目：100个农业与园艺条目，40个其他代表植物；条目不是独立物种数量。
- 85个地区案例；气候、根区与水源资料注明时期、单位、来源和适用边界。
- 437段预先生成的MiniMax录音；字幕和地球展示使用同一录音时钟。
- 国家农业统计、原生与引入记录、代表地区与气候候选分别表达。
- 按问题进入、课程目录、连续播放、植物对照和个人解释回顾。

进入后选择一个问题，或通过课程目录直接进入植物、地区与地理基础。点击播放才开始讲解；可以暂停、回看、展开地图，再回到当前讲解位置。

## 本地开发

需要Node.js 22及Python 3。运行`npm ci`，然后`npm run build`、`npm run check`。在项目目录运行`python -m http.server 8000`，访问`http://127.0.0.1:8000/`。

修改`src/`中的界面代码和根目录CSS后重新构建。`data.js`是经过校验的固定资料与录音清单；修改讲稿需要生成新的录音版本和字幕，不能直接改文字后沿用旧录音。

## 发布

推送`main`触发GitHub Actions：从源码构建、检查固定资料与资源、只将`site-files.json`列出的文件发布到GitHub Pages。所有页面资源使用相对路径，支持项目子路径。媒体为独立文件，按播放器或图片需要加载；首页不包含全库录音的Base64数据。

仓库中不含API密钥、付费接口回执、个人学习记录、原始抓取缓存、离线单文件或本机开发依赖。网站播放现有录音，不调用MiniMax付费接口。个人学习状态保存在访问者自己的浏览器中。

## 资料与表达边界

来源、许可及支持范围保存在`sources/`，也可在网站资料栏查看。植物实物照片的作者、许可和原始页面在`sources/plant-photos.json`；NASA地表图的来源与处理过程在`sources/earth-surface-provenance.json`。第三方代码许可证见`THIRD_PARTY_NOTICES.txt`。

国家生产统计、粗区系记录和地区采样点不能证明具体田块适生；教学模型、山形、风与水循环符号不是现场重建或实时观测。句内定位使用文字位置估算，不是逐词强制对齐。网站适合科普与比较学习，数据覆盖和缺失在界面明确说明。
