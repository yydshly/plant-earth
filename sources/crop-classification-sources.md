# 作物分类教学内容依据

四条路线、十三个用途类，覆盖当前100个农业条目。用途类允许交叉，不是正式植物谱系或FAO商品分类。代表路线只选1至3个当前真实条目；糖料2个，工业原料与饲草各1个。

每类教学分三步：认识用途 → 辨认食用/利用器官 → 比较代表及环境差异。每次只展示当步短段，来源收在展开入口。所有环境解释都为定性说明，不新增共同温雨阈值或适生范围。

逐条引用先读取当前environment profiles；来源原文范围保留在sources[].supports与cropId。初步分类关系另参考FAO农业普查分类和UNSD CPC根/块茎定义。额外形态资料用FAO天然纤维资料与Purdue扁桃植物识别页核对。

## 需要保留的认识边界

- 豆类不都以淀粉为主要利用线索；第一条路线称“粮豆与薯类”，不将大豆误说成主要淀粉作物。
- 谷物与伪谷物、蔬菜与植物学果实、食用坚果与植物学坚果分别说明；水果类按餐桌果品用途组织，也包含饮品或加工用途。
- 马铃薯块茎、甘薯储藏根、芋球茎区分。
- 豌豆与大豆的多重用途不创造新物种；甘蓝与甜菜的栽培群/用途类型也不作为完全独立物种范围。
- 乳胶不等同树脂；棉籽毛、亚麻/黄麻茎纤维与剑麻叶纤维分别说明。
- 饲草以实际现有苜蓿代表，不临时把其他条目改标饲草以凑数；固氮、耐旱生存与高产肥水需求分开。
